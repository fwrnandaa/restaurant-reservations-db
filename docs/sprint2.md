# 📖 User Stories Included in Sprint 2

---

## EPIC 1 — User Management

### User Story 1 — Register Customers

**As a** customer  
**I want** to register in the system  
**So that** my reservation information can be stored.

### Acceptance Criteria

- Registration form exists
- Required fields are validated
- Customer data is stored
- Confirmation message is displayed

---

### User Story 2 — Login into the System

**As a** customer  
**I want** to log into the system  
**So that** I can access reservation features.

### Acceptance Criteria

- Login form exists
- Credentials are validated
- Sessions are created correctly
- Error messages are displayed when needed

---

## EPIC 2 — Reservation Management

### User Story 3 — Create Reservations

**As a** receptionist  
**I want** to create reservations  
**So that** customers can reserve tables in advance.

### Acceptance Criteria

- Reservation form exists
- Reservation data is stored
- Reservation details are displayed
- Reservation records are saved successfully
